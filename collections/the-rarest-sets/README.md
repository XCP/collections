# The Rarest Sets

This project grouping includes the illustrated RARESTSETS parent, its four reviewed subassets, and the companion RARITYHOLDER artwork. The complete parent namespace was checked against xcpio-core; membership is explicit, not an automatic rule for future children. These entries include book ownership and auction memorabilia as well as artwork. The shared namespace, explicit printed project branding, exact project sources and reviewed media establish their relationship.

The [project website](https://therarestsets.com/index.html) displays the exact RARITYHOLDER artwork, links its token and explicitly credits @psyfrogger. The site image and CDN original show the same work at different resolutions. Reuse the existing psyfrogger artist profile.

[RARESTSETS.The_Rarest_Tote metadata](https://raw.githubusercontent.com/subterranean1/jsons/main/RARESTSETS.The_Rarest_Tote) credits subterranean x Amy DiGi; both existing individual credits are retained. The [book sale listing](https://scarce.city/goods/therarestsets) identifies the parent RARESTSETS as a proof-of-ownership token. The [book and tote auction](https://scarce.city/auctions/the-rarest-sets-pepetannica-hand-painted-tote-xcp) independently connects the project items. Parent and child works remain distinct, and no artist is inferred for the other entries from the issuing address.

The underlying Rare Pepe cards reproduced inside the book are not all admitted to this project collection. This record groups the project's own tokens and companion artwork, not its entire reference catalog.
