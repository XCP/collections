# Night Become Butterflies

The [creator’s February 2016 announcement](https://forums.counterparty.io/t/ann-night-become-butterflies-bitcoin-based-item-collectors-game/1803) explicitly lists these nine items. Their exact-asset Coindaddy JSON links the same development blog, and their pixel-art previews were reviewed. This is a documented subset, not a claim to capture all 52 items mentioned by the announcement or all assets issued from the address.

Artist attribution remains open: the designer posted as cassandralechat, but separately credits OceansDream for starter graphics. That does not establish who drew each item. Existing editorial attributes are preserved.
