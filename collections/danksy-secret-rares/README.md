This is an editorial grouping of three explicitly labeled Secret Rare subasset variants. The name combines the Danksy names and Secret Rare labels in their own issuance descriptions; it is not a claim that a separately published official catalog uses this exact collection title.

The issuance histories explicitly document these migrations:

| Earlier token | Replacement subasset |
| --- | --- |
| DANKSYDREAMS | DANKSYSTYLE.DREAMDANKSY |
| NOLOVEDANKSY | DANKSYSNOW.DANKSYLOVE |
| DANKSYSAVES | DANKMEMESY.DANKSYSAVE |

Each replacement's original description also identifies its appearance on the Too Many Danksys compilation card, TOOMNYDANKSY. Its animation shows DREAMDANKSY, DANKSYLOVE and DANKSYSAVE in frames 11, 12 and 13 (zero-based), corroborating the named relationships. This evidence establishes a coherent variant family, not official Dank Rares admission. The replacements were not found in the three available Dank Directory volumes.

The three illustrated namespace parents are secondary members here and keep their existing primary homes and artist credits in Dank Rares. No parent artist is automatically copied to a child. The older tokens were subsequently pointed at blank images and are not added here; no token identifiers are merged or replaced. GYPSYDANK is not part of the three documented migrations.

DANKSYSNOW has a historical attribution discrepancy: the WordPress directory says DOGESTYLE while the existing registry says jpegtrashbin. This change preserves the existing credit and records the disagreement for separate research.
