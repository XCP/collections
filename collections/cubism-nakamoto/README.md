## Membership evidence

Originally reviewed 2026-10-10 against the [project website](https://cubism-nakamoto.slidde.co/), exact xcpio-core subasset records and 22 reachable artwork JSON documents. Reviewed again on 2026-11-16: the [published project gallery](https://cubism-nakamoto.slidde.co/) now displays the master and CUBINAKAMOTO.00 through .24, with artwork images and Counterparty links for .22, .23, and .24. These three newly published works are added to this collection. The chain also contains reserved .25 through .60 identifiers; their registration alone is not evidence of completed artwork, so they are not automatically included.

CUBINAKAMOTO is the master; .00 is Genesis. The existing CUBINAKACASH and CUBINAKAREDO memberships represent related project utility tokens: the former is burned to submit a work, and the latter provides a retry for a rejected submission. They are not numbered gallery artworks.

This is a multiartist curated project. The website allows anonymous contributions, and the reachable JSON does not identify individual creators (one explicitly says Anonymous). Do not assign all works to the issuer or create an artist named Anonymous. Future credits require evidence specific to the artwork.
