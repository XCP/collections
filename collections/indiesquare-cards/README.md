A retrospective selection of independently issued personal and community cards using IndieSquare metadata in 2016–17. This is not an official IndieSquare series or a claim that all IndieSquare-hosted assets belong here. The registry uses a canonical primary home so these cards leave the Counterparty catch-all; that technical classification does not imply an original coordinated release.

## Membership

Included after inspecting the CDN artwork and valid on-chain issuance descriptions: portraits, personal avatars, and identifiable community or venue cards. Generic Counterparty placeholders, unrelated projects and assets whose only connection is the hosting domain are excluded. HORIECARD and HORIEMONCARD are distinct on-chain assets from the same issuer showing the same portrait; both are retained. No depicted person or issuing address is inferred to be the artist.

## Dates and evidence

The displayed 2016 year is a reviewed first-use estimate for the earliest cards, not the creation date of this retrospective grouping. Every member has a contemporaneous IndieSquare metadata reference in a valid issuance. Those mutable URLs establish the historical association, not immutable proof of the current image bytes; no exact Art year traits are asserted. The metadata host was unavailable during review.
