## Artwork chronology, reviewed 2026-10-13

On 2021-11-16 ownership transferred, 100 units were issued, the description changed to the current direct PUPS image, CHONK and SHEPHERD were created with their own images, and supply was locked. The old JSON URL alone does not date the present dog artwork to 2015.

Use 2021 for the documented emergence of this artwork family, supported by the coordinated ownership, media, supply and subasset events.
