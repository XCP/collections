# Complete collection date coverage, 2026-10-13

All 1,111 registry collections now carry `founded`: 186 existing reviewed dates are retained and 925 previously undated collections receive supported dates or documented first-use estimates. The live artist directory audit separately found 1,177 of 1,177 artists already have a displayed year; this change does not alter their artwork dates or credits.

## Meaning and method

A project year is not the first registration of one of its token names. For a named artwork family it dates supported activity in that family; for a variation group it dates the documented expansion, without automatically inheriting the original parent's age. A curated thematic grouping can use the earliest supported work in that grouping, but its README must not imply a contemporaneous formal organization or public launch when none is documented. These dates are editorial estimates where stated, not universally verified launch anniversaries.

Reviewed the existing membership evidence alongside valid issuance histories for 4,547 unique member assets. Resolve subasset longnames to numeric identities before requesting histories: an empty longname history is not evidence of no activity. Follow pagination. Exclude invalid transactions. Exclude old namespace parents where a child family is being dated, and start at a later supply reset where applicable. Existing individually reviewed Art year values remain authoritative; no artwork dates, artists, primary flags or memberships are changed.

Most added dates combine a matching media/JSON reference with positive edition issuance within 90 days, in the context of the already-reviewed family/catalogue. This is a practical first-use estimate. Mutable URLs do not prove historical image contents, so a recorded URL alone never establishes an early project. Supply locking, original artwork text, embedded SVG and existing catalogue evidence supplement that method. Previously reviewed Art year anchors are reused. A few dates use the first documented media after an existing edition as a conservative bound and are explicitly labelled that way.

The complete decision list, anchor assets, API history links, transaction hashes, event dates and basis labels are in [the evidence inventory](../data/collection-date-evidence-2026-10-13.json). Each affected collection README also records its date and limits. Existing membership sections supply the catalogue and visual-family context. The research snapshot was taken on 2026-10-13; stronger earlier release evidence can improve an estimate later.

## Exceptions and misleading early candidates

- **Lore Myths & Legends: 2022.** LORE's 2015 zero-supply registration contained a generic Coindaddy JSON pointer. The 2022 ownership transfer, 200-unit reset, new Easyasset reference and lock support actual use. The pointer does not make this a 2015 project.
- **Counterfeit Superfakes: 2022.** Project-labelled DISINFOCZARD supplies the anchor. XCHAINPEPE is a 2017 Rare Pepe included secondarily; it cannot backdate this project.
- **Hip-Hop Elements: 2016.** The creator's documented original four-card set supplies the anchor, rather than the later framed token. Its original Rare Pepe memberships remain primary.
- **BOGS: 2019; CANHEAD: 2023; INVISIBLHAND family: 2022.** Blank child descriptions require edition/context estimates, supported by the already-reviewed images and named child editions. These are not claimed historical upload dates. INVISIBLHAND's original individual artwork remains dated 2018.
- **Cornfiftyone: 2022; Cornmio: 2021.** Artwork-specific text accompanies the named variant edition and lock and agrees with reviewed imagery.
- **Memestacks and Mempepe: 2026.** SVG art is embedded directly in the issuance alongside positive supply.
- **MIKEINSPACE variation: 2022; SHART variation: 2024.** Exact child artwork references and reviewed images document artwork activity, but the child histories show zero issued supply. These dates do not claim edition releases or sales. SHART's 2015 reservation is explicitly excluded.

The repository source-coverage check now rejects missing collection years. Contributors must supply evidence or a documented estimate, rather than rely on a marketplace registration-date fallback. The normalized metadata contract remains backwards compatible for external feeds and fixtures.
