# Deeper collection consolidation review — 2026-10-13

## Scope and limits

Follow-up to the initial consolidation review: all 100 shared-address candidate groups were screened using their registered membership, descriptions, existing source notes and representative CDN artwork. They cover 373 distinct collection entries after the Emblem retirement. Of 373 representative requests, 372 rendered; the Crypsi HODL representative returned HTTP 415 and that group’s visual coverage is incomplete. An additional 39 artist-linked collection representatives were viewed. This is collection-level triage with focused source checks, not a new inspection of every asset or every animation frame. Existing source notes are not described as fresh external verification.

## Changes and boundaries

- Fold the two Pizza Day Note tokens into Vizique’s ten-member Banknote Series. Fresh token JSON and the artist’s gallery resolve both images. Add a Design facet; preserve distinct token identities, credits and official Dank Rares primary memberships. See the collection README for exact sources.
- Keep Weex’s 2015 originals separate from the explicitly labelled 2023 backup tokens. The backups are evidence about the artworks, not 2015 issuances. Merging would obscure provenance and age.
- Keep Fake Space episodes and Fake Space Dub separate for now. A cassette template is not sufficient evidence of one project; existing source notes describe an episode series and a music family. No new source established equivalence.
- Keep official XCPinata categories, Bitcoin Heads versus Leftist Tears, KOKO versus PUPS, and the named Crypsi/Vizique/S1MONS families. A creator can have more than one project.
- Preserve intentional subsets and overview memberships, including Hip-Hop Elements and Vadam Kadmon. Overlap alone is not a duplicate identity.

A cross-reference of previously recovered JSON covered 276 of 2,804 candidate member records and found no additional shared original media across distinct tokens/collections. That partial negative result is not proof that all other media differ. The fresh Pizza Day JSON is stronger positive evidence than this partial cache.
